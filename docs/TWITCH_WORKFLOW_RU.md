# Быстрый сценарий для разговорного Twitch-стрима

## Первый запуск

Готовая сборка для macOS Apple Silicon уже содержит backend, Python и FFmpeg:
достаточно открыть `.dmg` и перенести ScriptCut в Applications. Node.js и
командная строка друзьям не нужны.

Сборка пока не подписана сертификатом Apple. При первом запуске используйте
**Control-клик → Открыть** и подтвердите запуск.

Для запуска из исходников нужны Node.js 18+, Python 3.11 и FFmpeg:

```bash
brew install python@3.11 ffmpeg
npm run setup
npm run doctor
npm run dev
```

`npm run setup:optional` отдельно добавляет тяжёлое локальное удаление фона.
Базовая расшифровка работает через Faster Whisper с таймингами каждого слова,
а очистка звука без дополнений использует фильтр FFmpeg.

## Тематическая нарезка

1. Откройте запись стрима и дождитесь расшифровки.
2. В панели **AI Editor** напишите, что должно остаться. Например:
   `оставь все рассуждения о том, почему беременность плохо оптимизирована`.
3. Выберите запас на границах. Для разговора обычно достаточно `0.4–0.8 сек`.
4. Нажмите **Найти по теме**.
5. Прослушайте зелёные найденные эпизоды. Ниже находятся участки, предложенные
   к удалению.
6. Отклоните сомнительные удаления или применяйте их по одному. Кнопка
   **Apply Pending** применяет только неотклонённые предложения.

Длинная расшифровка не отправляется одним гигантским запросом. Приложение
проверяет её блоками, объединяет совпадения и отдельно уточняет начало и конец
каждого найденного разговора.

## Цензура

1. Откройте вкладку **Цензура**.
2. Оставьте включённым русский словарь мата и при необходимости добавьте свои
   слова или целые фразы через запятую либо с новой строки.
3. Выберите замену: **Бип**, **Тишина** или **Фоновый шум**.
4. Проверьте отдельные совпадения и примените их вручную либо используйте
   **Применить ко всем**.

Поиск слов выполняется локально. При предварительном просмотре бип
воспроизводится как тишина, а при экспорте FFmpeg добавляет звуковой сигнал.

## Субтитры и Shorts

- В окне экспорта выберите `TikTok / Reels` или `YouTube Shorts`, кадр `9:16`
  и один из стилей субтитров: Clean, Creator или Karaoke.
- `Burn-in` встраивает субтитры в видео, если FFmpeg собран с `libass`;
  текущая переносимая сборка автоматически использует проверенный `.srt`
  рядом с роликом.
- Во вкладке **Create Clips** можно создавать и пакетно экспортировать несколько
  коротких вертикальных роликов.

## AI-провайдер

- **Ollama** — расшифровка и видео остаются локально; текст запроса обрабатывает
  локальная модель.
- **OpenAI**, **Claude**, **Grok** — в облако отправляется только текст
  расшифровки выбранного действия, не исходный видеофайл.
- Ключи сохраняются через защищённое хранилище Electron.

Для Grok используется официальный адрес `https://api.x.ai/v1`. Ключ задаётся
в настройках, модель по умолчанию — `grok-4.5`.
